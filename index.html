🔑 Obtenir un token API

Suis ces 5 étapes pour connecter ton compte Cloudflare.

1
Connecte-toi à ton compte sur Cloudflare Dashboard .
2
Clique sur ton profil en haut à droite, puis sur My Profile.
3
Ouvre l'onglet API Tokens, puis clique sur Create Token.
4
Choisis Create Custom Token et configure les permissions suivantes :
✓ Account → Read
✓ Workers Scripts → Read
✓ Workers Scripts → Write
Dans Account Resources, sélectionne le compte Cloudflare concerné.
5
Clique sur Continue to summary, puis Create Token. Copie le token généré et colle-le dans le champ de connexion de cette application.
⚠️ Important : le token n'est affiché qu'une seule fois. Copie-le immédiatement et ne le partage jamais.
